# Buck Converter (12 V → 5 V)

Design and simulation of a **12 V to 5 V step-down (buck) DC–DC converter**.

## Contents

- **`12V_to_5V_Buck/`** — KiCad schematic, PCB layout, and a 3D STEP model of the converter.
- **`LTspice/`** — LTspice simulation schematics and operating-point results.

## Website

An interactive project website lives at:

**https://jatt47508.github.io/Buck-Converter/**

## Notes

- KiCad auto-backup history and lock files, plus LTspice raw/log output, are ignored by git.
- Simulation results are simulated values, not measured hardware data.
